# 0.3 两种世界与画面动画验收

日期：2026-11-17。代码分支 `feat/animated-storybook-worlds`，[PR #6](https://github.com/nkvic520/and-there-was/pull/6) 建立在尚未合并的 [PR #4](https://github.com/nkvic520/and-there-was/pull/4) 上；任务 [#5](https://github.com/nkvic520/and-there-was/issues/5)。本阶段不创建 Codespaces、公开演示或 Release。

## 交付范围

- 空画布选择动态动画或静态漫画／绘本，默认动态；生成后模式固定，另一模式通过新世界创建。
- SDK 3 提供曲线路径、渐变、描边、文字、组合层级和受限关键帧。连续动作、点击后重新播放、入场与位置过渡由宿主渲染；生成脚本仍在隔离运行时内执行。
- 动态世界可暂停，时间与动作起点保存到 SQLite；静态页不持续运行 ticker，按整页内容适配手机。
- 协议、view 和世界 mode 一致才允许生效；静态模式拒绝动画、入场和事件；保留 SDK 1/2 旧作品。
- 动画检查点独立于语义版本。突然关闭可能丢失尚未送达的播放时间，不影响已提交状态。三个月逐轮清理规则继续保留当前作品。

## 真实 DeepSeek

实际使用本机 `.env` 中的 `deepseek-flash`，提示词 `scene-sdk-3/2026-11-17.3`，没有将密钥或原始会话提交到 Git。

| 输入 | 最终试跑和提交结果 |
| --- | --- |
| 森林里的小狐狸、摆动尾巴、萤火虫，点击后跳跃 | 50 个节点、25 个动画节点、18 个曲线路径、1 个事件绑定；14.31 秒，一次通过 |
| 三格漫画：狐狸发现光、追到树下、找到小门，中文旁白 | 66 个节点、16 个曲线路径、4 个文字节点、无动作和绑定；10.83 秒，一次通过 |

以上时间是 API 请求到隔离试跑、保存完成，不包含随后打开页面的时间。用生成的实际包完成状态事件执行、服务关闭再打开、快照一致性和播放信息恢复。另用 Edge 与手机尺寸的 Edge 自动化查看这些实际包，4/4 检查通过：持续运动、组合对象点击／触摸、静态像素不变、无页面脚本错误。人工检查截图后，修正了手机整页裁切，并增加中文旁白字号指引。

调试中遇到过模型坐标误解、错误 schema、motionKey 放错位置、圆形尺寸不一致，以及原先 2MiB SSE 上限不足。已经改进提示词、诊断和有界流式容量；失败尝试保留记录，未替换当前场景。这些结果不代表任意输入均能一次生成成功，也不代表构图和动作均达到美术成品质量。

## 复现

1. `npm ci`，无 `.env` 时使用样例模式；`npm run dev` 打开 5173。生产用 `npm run build`、`npm start` 打开 3000。
2. 首页选动态动画，发送「有一个球」，观察球反复弹跳；暂停，保留完整 `/w/` 地址，重启后用新浏览器上下文恢复。
3. 点新世界、选静态漫画／绘本、发送相同句子，检查标题、插画、旁白；等待后画面不应变化，重启恢复同一页。
4. 配置真实 DeepSeek 后生成上表两种内容；动态世界可继续用文字增加规则，绘本可用文字续改画面。失败时检查档案和“再试一次”。
5. `npm run check`、`npm run build`、`npm run test:e2e`；具备 Docker 时运行 `npm run test:container`。

完整物理、碰撞、寻路、生成贴图、骨骼动作、音效、撤销和作品导出不属于本轮交付。
