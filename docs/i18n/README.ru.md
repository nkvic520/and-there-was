# And There Was…

[English](../../README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Português (Brasil)](README.pt-BR.md) · **Русский**

Из одной идеи рождается маленький мир. Холст для детей и взрослых, которые творят вместе с ними.

## Что можно делать

- Начните с пустого холста и добавьте мяч одной фразой.
- Описывайте и меняйте мир с помощью OpenAI или DeepSeek, добавляя взаимодействие мышью или касанием.
- Выберите анимированный мир или неподвижную страницу комикса либо книжки с картинками.
- Создавайте изображения с OpenAI или Seedream, выбирайте бесплатные материалы или загружайте собственные рисунки ребёнка.
- Продолжайте на том же холсте и возвращайтесь к работе по сохранённой ссылке.

Интерфейс доступен на десяти языках. При первом открытии он учитывает языки браузера и выбирает английский, если совпадений нет. Устройство запоминает выбор в меню языков. Язык истории сохраняется отдельно для каждого мира.

## Попробовать демо

Запустите приложение локально и отправьте **Есть мяч**, чтобы попробовать его без ключа. Ссылка на публичную демонстрацию появится, когда она будет доступна.

Выберите картинки в разделе **Картинки / мои рисунки** и отправьте **Используй выбранные картинки**.

## Размещение на своём сервере

Клонируйте или скачайте репозиторий. В корневой папке скопируйте [`.env.example`](../../.env.example) в `.env`. Настройки по умолчанию запускают пример без ключей API.

### С Docker Compose

```sh
docker compose up --build -d
```

Откройте [http://127.0.0.1:3000](http://127.0.0.1:3000). Compose хранит работы в томе `world-data`; сохраняйте его при перезапуске и обновлении.

### С Node.js

Нужны **Node.js 24.11.1 или более новая версия Node 24**, а также npm. Выполните в корне репозитория:

```sh
npm ci
npm run build
npm start
```

[http://127.0.0.1:3000](http://127.0.0.1:3000)

Для телефона в той же доверенной сети после сборки выполните `npm run start:lan` и откройте локальный сетевой адрес компьютера, указанный в терминале.

## Настройка окружения

Задайте значения в `.env` и перезапустите сервис после изменений. Храните ключи API только на сервере. Уже заданные переменные окружения имеют приоритет над `.env`.

| Параметр | Назначение |
| --- | --- |
| `HOST` | Адрес прослушивания; по умолчанию `127.0.0.1`. |
| `PORT` | HTTP-порт; по умолчанию `3000`. |
| `DATA_DIR` | Папка работ и записей; по умолчанию `./data`. |
| `GENERATOR_MODE` | По умолчанию выбор автоматический. Режим `fixture` включает локальные примеры. |
| `OPENAI_API_KEY / OPENAI_TEXT_MODEL / OPENAI_IMAGE_MODEL` | Ключ проекта и модели для сцен и изображений. |
| `DEEPSEEK_API_KEY / DEEPSEEK_MODEL / DEEPSEEK_BASE_URL` | Ключ API, модель и адрес DeepSeek. |
| `SEEDREAM_API_KEY / SEEDREAM_MODEL / SEEDREAM_BASE_URL / SEEDREAM_SIZE` | Ключ API, модель, адрес и размер изображения Seedream. |

### Сервисы ИИ

Укажите `OPENAI_API_KEY` своей организации API и перезапустите приложение. OpenAI будет создавать сцены и иллюстрации, даже если сохранены ключи DeepSeek и Seedream.

Если удалить ключ OpenAI и перезапустить приложение, `DEEPSEEK_API_KEY` включит создание сцен, а `SEEDREAM_API_KEY` — генерацию иллюстраций. Бесплатные материалы и загруженные рисунки можно размещать на холсте напрямую.

Поставщики могут взимать плату за реальные запросы к моделям. Сохранённую работу можно открыть без повторной генерации.
