# 使用帮助

[项目说明](../../docs/i18n/README.zh-CN.md) · [English](README.md)

## 创建和重新打开世界

打开首页会创建空世界。输入 **有一个球**，点击箭头发送。中文输入法选字或按 Enter 不会发送整句，请使用发送按钮。

地址会变成 `/w/<worldId>`。请收藏或保存**完整地址**，以后用它回到同一作品。首页总是创建另一个世界。只要保留数据，重启服务后也能打开原来的作品。

应用界面目前为简体中文。内置样例识别准确的中文句子，请按示例输入。

## 选择世界类型

- **动态动画：** 持续活动的世界，可以加入鼠标点击和触摸互动。使用“暂停动画”和“播放动画”控制播放。
- **静态漫画／绘本：** 静止的插画或漫画页面，可带文字。

创建世界时选择类型。要换一种作品，请点“新世界”。如果设备设置了减少动态效果，动画默认暂停，可手动点击播放。

## 使用 DeepSeek 自由创作

在 `.env` 设置 `GENERATOR_MODE=deepseek` 和自己的 `DEEPSEEK_API_KEY`，然后重启。可以描述一个场景，再继续向同一个世界提出要求，例如先发送 **要有光**，再发送 **碰三次出现一扇门**。

生成需要一些时间，也可能失败。“再试一次”会发起新的模型请求，可能产生费用。尝试失败时，最近保存成功的场景仍然保留。

将 `GENERATOR_MODE` 设为 `fixture` 可使用免密钥样例。该模式识别 **有一个球** 和 **使用选中的素材**，不能处理任意句子。

## 选择画面素材

打开输入框下方的素材入口。素材来源和世界类型可以独立选择。

### AI 画图

除 DeepSeek 外，还需要配置 Seedream。新场景的背景和角色可以分别生成，让角色独立活动；修改动作时可以复用已有图片。目前图片角色可以移动、缩放、旋转和响应点击，单张图片不等于具备独立四肢动作的角色。

### 素材／我的作品

勾选内置图片，或上传自己的画作。为上传图片命名，并选择“角色／贴纸”“背景”或“整页画作”。选中的图片会随下一句话加入世界。样例模式可发送 **使用选中的素材** 来体验。

- 支持最大 **8 MB** 的静态 PNG、JPEG、WebP。大照片被拒绝时，可以先缩小图片尺寸。
- 原件会保留，显示副本会按正确方向处理并在需要时缩小。画纸背景会保留，上传不会自动抠图或改画。
- 在 AI 画图模式中，只有勾选“允许把选中的上传作品发给 Seedream 作为参考图”，才允许将本次选中的上传图发给 Seedream。单纯上传或选图不代表授权。
- 内置 [Kenney 素材](../../fixtures/library/README.md) 采用 CC0 许可，不作为图片模型参考图。已有 Seedream 图片可以作为后续编辑的参考。

上传和使用免费素材本身不调用 Seedream。在 `GENERATOR_MODE=deepseek` 模式下，场景编排仍会调用 DeepSeek。

## 安装和环境配置

在仓库根目录将 `.env.example` 复制为 `.env`，该文件只保留在本机。

Windows PowerShell：

```powershell
Copy-Item .env.example .env
```

macOS 或 Linux：

```sh
cp .env.example .env
```

若已有 `.env`，请直接编辑，避免覆盖已有配置。选择一种启动方式：

| 方式 | 环境要求 | 命令 |
| --- | --- | --- |
| Docker Compose | Docker 和 Compose | `docker compose up --build -d` |
| Node.js | Node 24.11.1 或更新的 Node 24 版本，以及 npm | `npm ci`、`npm run build`、`npm start` |

打开 [http://127.0.0.1:3000](http://127.0.0.1:3000)。Node 启动命令会读取根目录 `.env`；进程中已有的环境变量优先。修改配置后需重启服务。

| 配置项 | 默认值 | 用途 |
| --- | --- | --- |
| `HOST` | `127.0.0.1` | Node 服务监听地址。 |
| `PORT` | `3000` | Node HTTP 端口。 |
| `DATA_DIR` | `./data` | 保存作品和记录的目录。 |
| `PUBLIC_ORIGIN` | 未设置 | 使用会改写 Host 的认证反向代理时，填写准确的公网来源，例如 `https://example.com`。 |
| `GENERATOR_MODE` | `fixture` | 改为 `deepseek` 使用真实模型。 |
| `DEEPSEEK_API_KEY` | 空 | 服务端 DeepSeek 密钥。 |
| `DEEPSEEK_BASE_URL` | `https://api.deepseek.com` | DeepSeek 服务地址。 |
| `DEEPSEEK_MODEL` | `deepseek-flash` | 使用的模型。 |
| `ARCHIVE_RETENTION_MONTHS` | `3` | 支持的真实记录保留月数。 |
| `SEEDREAM_API_KEY` | 空 | 服务端火山方舟密钥。 |
| `SEEDREAM_BASE_URL` | `https://ark.cn-beijing.volces.com/api/v3` | Seedream 服务地址。 |
| `SEEDREAM_MODEL` | `doubao-seedream-5-5-261028` | 已开通的模型或 Endpoint ID。 |
| `SEEDREAM_SIZE` | `2K` | 请求的图片尺寸。 |

需要在火山方舟账号中开通所选 Seedream 模型。默认模型支持应用使用的图片参数；更换其他模型时，也需要支持这些参数。

Compose 在 `compose.yml` 中固定容器内部的监听地址、端口和数据目录，并将主机的本机地址端口 3000 映射到容器。需要换端口时，在该文件修改映射。模型配置从根目录 `.env` 读取。

## 手机与网络访问

在同一可信网络中访问时，先构建应用，再运行 `npm run start:lan`，用手机打开终端打印的电脑局域网地址。手机上的 `127.0.0.1` 指向手机自己。若电脑局域网地址打不开，请检查网络互通和电脑防火墙。

应用没有内置账号系统，适合单所有者的私有实例。公网部署需在页面和 API 前配置 HTTPS 及身份认证。若代理改写 Host，还需设置 PUBLIC_ORIGIN；使用 Compose 时，也要将它加入 compose.yml 中 app 服务的环境变量。目前没有公开托管的演示地址。

## 保存、备份和恢复

Node 部署保留 `DATA_DIR` 指向的整个目录；Compose 部署保留 `world-data` 卷。备份前停止服务，完整复制数据，恢复时将整份副本放回原数据位置。删除目录或卷会删除保存的作品。

升级或重启后，请打开完整的世界链接，而非首页。已保存的游戏状态和动画进度会恢复；突然退出可能丢失尚未保存的动画播放进度。重新打开已有世界不会再次调用模型。

真实记录**逐条保留三个日历月**。当前作品及其需要的文件继续保留；过期原文、模型请求响应和不再需要的历史记录会自动清理。未使用的上传或生成图片也在三个月后到期，当前作品仍使用的图片与原件会保留。内置样例记录继续保留，但使用真实上传素材的样例按真实记录处理。自行另存的备份以及供应商侧记录遵循各自的保留规则。

所有者可打开 `/inspect/<worldId>` 查看保存的输入、生成内容和版本，以及图片来源和原件下载。这是与创作画面分开的所有者查看入口。

## 常见问题

**为什么作品不见了？** 请打开完整的 `/w/<worldId>` 地址，并确认服务使用原来的数据目录或卷。首页总是创建新世界。

**为什么输入的句子没有用？** `fixture` 模式只支持上面列出的样例句子。需要自由创作时，请配置 DeepSeek 并重启服务。

**为什么手机打不开？** 请使用电脑局域网地址，确认设备之间网络互通，并允许应用端口通过电脑防火墙。

**为什么生成失败？** 检查配置的服务商、模型开通状态和账户余额。更新密钥或模型后重启。访问 `/api/health` 可查看当前模型及图片模型是否已配置，不会显示密钥。生成失败时可以重试，之前保存的作品会保留。

**为什么画面不动？** 绘本模式本来就是静态的。动态模式下，请检查播放／暂停按钮和设备的减少动态效果设置。
