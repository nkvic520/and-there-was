# 使用帮助

[项目说明](../../docs/i18n/README.zh-CN.md) · [English](README.md)

## 创建和重新打开世界

打开首页会创建空世界。输入 **有一个球**，点击箭头发送。中文输入法选字或按 Enter 不会发送整句，请使用发送按钮。

地址会变成 `/w/<worldId>`。请收藏或保存**完整地址**，以后用它回到同一作品。首页总是创建另一个世界。只要保留数据，重启服务后也能打开原来的作品。

应用界面目前为简体中文。内置样例识别准确的中文句子，请按示例输入。

## 安装和环境配置

在仓库根目录将 `.env.example` 复制为 `.env`，该文件只保留在本机。

Windows PowerShell：

```powershell
Copy-Item .env.example .env
```

macOS 或 Linux：

```sh
cp .env.example .env
```

若已有 `.env`，请直接编辑，避免覆盖已有配置。选择一种启动方式：

| 方式 | 环境要求 | 命令 |
| --- | --- | --- |
| Docker Compose | Docker 和 Compose | `docker compose up --build -d` |
| Node.js | Node 24.11.1 或更新的 Node 24 版本，以及 npm | `npm ci`、`npm run build`、`npm start` |

打开 [http://127.0.0.1:3000](http://127.0.0.1:3000)。Node 启动命令会读取根目录 `.env`；进程中已有的环境变量优先。修改配置后需重启服务。

| 配置项 | 默认值 | 用途 |
| --- | --- | --- |
| `HOST` | `127.0.0.1` | Node 服务监听地址。 |
| `PORT` | `3000` | Node HTTP 端口。 |
| `DATA_DIR` | `./data` | 保存作品和记录的目录。 |
| `PUBLIC_ORIGIN` | 未设置 | 使用会改写 Host 的认证反向代理时，填写准确的公网来源，例如 `https://example.com`。 |

Compose 在 `compose.yml` 中固定容器内部的监听地址、端口和数据目录，并将主机的本机地址端口 3000 映射到容器。需要换端口时，在该文件修改映射。

## 手机与网络访问

在同一可信网络中访问时，先构建应用，再运行 `npm run start:lan`，用手机打开终端打印的电脑局域网地址。手机上的 `127.0.0.1` 指向手机自己。若电脑局域网地址打不开，请检查网络互通和电脑防火墙。

应用没有内置账号系统，适合单所有者的私有实例。公网部署需在页面和 API 前配置 HTTPS 及身份认证。若代理改写 Host，还需设置 PUBLIC_ORIGIN；使用 Compose 时，也要将它加入 compose.yml 中 app 服务的环境变量。目前没有公开托管的演示地址。

## 保存、备份和恢复

Node 部署保留 `DATA_DIR` 指向的整个目录；Compose 部署保留 `world-data` 卷。备份前停止服务，完整复制数据，恢复时将整份副本放回原数据位置。删除目录或卷会删除保存的作品。

升级或重启后，请打开完整的世界链接，而非首页。

样例记录持续保留，直到所有者删除实例数据。

所有者可打开 `/inspect/<worldId>` 查看保存的输入、生成内容和版本。这是与创作画面分开的所有者查看入口。

## 常见问题

**为什么作品不见了？** 请打开完整的 `/w/<worldId>` 地址，并确认服务使用原来的数据目录或卷。首页总是创建新世界。

**为什么输入的句子没有用？** 该版本使用内置样例，请准确输入 **有一个球**。

**为什么手机打不开？** 请使用电脑局域网地址，确认设备之间网络互通，并允许应用端口通过电脑防火墙。
